BIRTHDAY SURPRISE - HOW TO USE

1. Unzip this folder. Keep everything together.
2. Double-click index.html to open it in your browser.
3. Click the surprise button to start.

FILES
  index.html, style.css, script.js   the website
  assets/wife-photo.jpg              main photo
  assets/photo2.jpg ... photo5.jpg   extra photos (add photo6.jpg if you like)
  assets/birthday-song.mp3           the song

EDIT MESSAGES: open script.js in Notepad, change the text at the top (CONFIG).
PUBLISH ONLINE: drag the whole folder onto app.netlify.com/drop
