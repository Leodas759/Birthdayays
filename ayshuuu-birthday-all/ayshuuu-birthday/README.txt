AYSHUUU BIRTHDAY GIFT - 26.10.2026

Two things are inside. Open each one by double-clicking its index.html.

1) surprise-website/   the birthday video-style website (music, photos, roses, hearts)
   - Keep the assets folder next to index.html
   - Photos: assets/wife-photo.jpg, photo2.jpg ... photo5.jpg (add photo6.jpg if you like)
   - Song: assets/birthday-song.mp3
   - Change messages, name, date: open script.js in Notepad, edit the CONFIG block at the top

2) greeting-card/      the greeting card (tap to open, 6 pages)
   - A single file: index.html (photos are built in)
   - Swipe left/right or use Prev / Next

PUBLISH ONLINE: drag a whole folder (surprise-website or greeting-card) onto app.netlify.com/drop
On Render: choose "Static Site", Publish Directory = the folder name, Build Command empty.
